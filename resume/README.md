# Resume

Two independent resume formats. Each folder has everything it needs to build on its own.

| Folder | Format | Content lives in |
|---|---|---|
| [v1](v1) | Original layout using the `russell.cls` class and Roboto fonts, built with XeLaTeX | `v1/sections/*.tex` |
| [v2](v2) | Classic single column serif layout with bold metrics, built with LuaLaTeX | `v2/resume.yaml` |

See the README in each folder for build and editing instructions.
